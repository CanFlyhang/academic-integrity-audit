# 详细执行指南

本文档是 SKILL.md 中执行流程的补充说明，提供更细粒度的操作指引。

## 第一阶段：分析 AIGC 报告

### 1.1 读取标红文档

AIGC 检测报告通常是 Word 文档，段落中不同颜色的 run 代表不同置信度：

- **红色**（如 FF0000、C00000）：高 AI 概率，必须重写
- **紫色**（如 800080、993399）：中等 AI 概率，优先重写
- **黑色/默认色**：未标记，一般不改

### 1.2 提取标红段落

用 python-docx 遍历所有段落的 runs，检查 `run.font.color.rgb`，按颜色分类提取。

### 1.3 计算标记率

```
AIGC率 = 被标记段落的总字符数 / 全文总字符数 × 100%
```

## 第二阶段：优先级排序

按以下优先级分配改写精力：

| 优先级 | 条件 | 原因 |
|-------|------|------|
| P1 | 红色 + 200字以上 | 单段贡献最大，改写收益最高 |
| P2 | 红色 + 200字以下 | 必须改但投入较小 |
| P3 | 紫色 + 200字以上 | 中等风险，提升整体效果 |
| P4 | 紫色 + 200字以下 | 低优先，有余力再改 |
| P5 | 未标记但含禁用短语或句长均匀 | 预防性改写，防止后续轮次复发 |

## 第三阶段：迭代改写循环（核心机制）

### 循环规则

| 规则 | 说明 |
|------|------|
| 硬性最少轮次 | 10轮。第1-9轮无论偏差多低都必须继续 |
| 退出条件 | 第10轮起，偏差 < 10% 即退出 |
| 硬性上限 | 20轮。超过20轮仍有偏差则输出当前版本并附警告 |
| 问题反馈 | 每轮质量检查发现的问题喂入下一轮优先级列表 |
| 策略偏移 | 1-3轮重改写；4-6轮调节奏+个人声音；7-10轮扫残留+一致性检查 |
| 稀释上限 | 新增稀释段仅在1-3轮添加，累计不超过9段 |

### 偏差评分（每轮计算）

偏差 = AI短语残留×0.30 + 句长均匀度×0.25 + 个人声音缺口×0.20 + 并列结构残留×0.15 + 元叙述残留×0.10

- 0% = 完全符合理想状态
- 100% = 完全AI风格

### 各轮次策略分配

**第1-3轮（深度改写）**：
1. 策略2、6、11：短语替换
2. 策略1、3、5：结构调整
3. 策略4、7、8、9：声音与风格
4. 策略10：新增稀释段落

**第4-6轮（精细调优）**：
- 策略1：检查每段是否有8字以下+35字以上句长交替
- 策略4：补充个人操作细节，确保每3-4段有1处
- 策略5：数据嵌入叙事的完整性检查
- 策略12：引入逻辑跳跃和岔开

**第7-10轮（残留清扫+一致性检查）**：
- 策略2、6：全文扫描是否有遗漏的禁用短语
- 策略11：删除残留的元叙述
- 跨段一致性：检查"说到底""笔者"等替代表达是否使用过于重复
- 数据准确性最终核对：统计值、p值、样本量未被改动

## 第四阶段：全文扫描（每轮执行）

改完标红段落后，全文扫一遍：
1. 检查是否有遗漏的禁用短语
2. 检查句长分布是否仍过于均匀
3. 检查讨论/结论是否有个人声音
4. 检查是否有重复使用的替代词（避免创造新模式）

## 第五阶段：质量偏差检查（每轮执行）

每轮改写完成后，计算5维偏差评分：

| 维度 | 权重 | 理想状态 | 测量方式 |
|------|------|---------|---------|
| AI短语残留率 | 30% | 零残留 | 禁用短语命中数 / 总段落数 |
| 句长均匀度 | 25% | 高方差 | 1 - (每段平均句长标准差 / 理想标准差15) |
| 个人声音覆盖率 | 20% | 每3-4段1处 | 1 - (含个人声音段数 / 总段数 × 4) |
| 并列结构残留 | 15% | 零残留 | 均匀并列结构数量 |
| 元叙述残留 | 10% | 零残留 | 元叙述句数 / 总句数 |

偏差 < 10% 且已达第10轮 → 输出
偏差 ≥ 10% 且未达第20轮 → 记录问题，喂入下一轮优先级，回到第三阶段
偏差 ≥ 10% 且已达第20轮 → 输出当前版本并附警告

## 第六阶段：生成输出

保存为新的 .docx 文件，保留原文档格式。输出报告：
- 执行轮次
- 最终偏差评分
- 累计改写段落数
- 新增段落数
- AIGC 率变化轨迹：基线 → 最终（逐轮记录）
- 需手动处理的残留问题列表

## 常见问题

### Q: 改写后某些段落的学术性下降怎么办？

A: 个人声音应该用在讨论、方法、结论部分。数据呈现和统计分析部分保持正式表达，但避免使用禁用短语。

### Q: 英文论文怎么用？

A: 禁用短语表已包含英文对照。策略1-12同样适用，但口语化程度要降低——英文学术写作本身比中文更正式，过度口语化反而异常。

### Q: 一篇论文需要改几轮？

A: 本Skill采用迭代循环机制，最少10轮，最多20轮：

- 初始 70%+：通常需要 10-12 轮（偏差降至10%以下后退出）
- 初始 40-50%：通常需要 10-11 轮
- 初始 20-30%：通常需要 10 轮（第10轮偏差可能已低于10%即退出）
- 硬性最少10轮：无论偏差多低，前9轮不会退出
- 硬性上限20轮：超过20轮仍有偏差则输出当前版本并附警告

### Q: AIGC 率降到多少算安全？

A: 一般低于 15% 即可通过大多数检测。低于 10% 几乎不会被标记。但不同检测平台阈值不同，建议以目标平台为准。
