# AIGC Reducer Skill

降低学术论文 AIGC 检测率的 TRAE Skill，通过 12 条改写策略将 AI 生成痕迹从 70%+ 降至 15% 以下。

## 适用场景

- 论文 AIGC 检测率过高，需要降低
- 收到 AIGC 检测报告（标红/标紫段落），需要逐段改写
- 希望让 AI 辅助写作的论文通过查重平台的 AIGC 检测

## 安装方式

将本仓库克隆到 TRAE 的 skills 目录：

```bash
git clone https://github.com/CanFlyhang/academic-integrity-audit.git
```

或在 TRAE 中通过 GitHub 链接安装。

## 迭代自检机制

本Skill内置迭代执行循环，每次执行后自动进行质量偏差检查：

- **硬性最少10轮**：无论偏差多低，前9轮不会提前退出
- **偏差 < 10% 退出**：第10轮起，偏差低于10%即结束
- **硬性上限20轮**：超过20轮仍有偏差则输出当前版本并附警告
- **问题反馈循环**：每轮检查发现的问题自动喂入下一轮优先级列表

偏差评分5个维度：AI短语残留(30%) + 句长均匀度(25%) + 个人声音缺口(20%) + 并列结构残留(15%) + 元叙述残留(10%)

## 效果验证

在某篇新工科人才选拔研究论文上经过 8 轮迭代测试：

| 轮次 | AIGC 检测率 | 降幅 |
|------|------------|------|
| 初始 | 76% | - |
| 第1轮 | 65% | -11% |
| 第2轮 | 53.79% | -11% |
| 第3轮 | 41.53% | -12% |
| 第4轮 | 33.97% | -8% |
| 第5轮 | 30.56% | -3% |
| 第6轮 | 28.27% | -2% |
| 第7轮+手动修改 | 9.97% | -18% |

## 12 条核心策略

1. **句长极端变化** — 每段混入 3-7 字短句和 40+ 字长句
2. **消灭 AI 模板短语** — 禁用"本研究旨在""综上所述"等 18 个高频句式
3. **打碎并列结构** — 并列项故意不等长、不等格
4. **注入个人声音** — 加操作细节、试错经历、真实困惑
5. **数据嵌入叙事** — 不再一个数据一句话，揉进叙述
6. **学术搭配口语化** — "系统性漏检"→"大概率被漏掉了"
7. **摘要结构破局** — 问题驱动替代"背景→方法→结果→结论"
8. **定义方式替换** — 用举例和对比替代"是指……"公式
9. **试错与自我修正** — "一开始试过切三档，太粗，后来改五档"
10. **稀释段落** — 插入 2-3 段个人经历，降低整体 AIGC 率
11. **消灭元叙述** — 删除"本文将从以下方面分析"
12. **不完美逻辑流** — 偶尔跳跃、岔开、延迟解释

## 使用方式

安装后，在 TRAE 对话中直接说：

- "请帮我执行 aigc-reducer"
- "我的论文 AIGC 率太高了，帮我降低"
- 上传 AIGC 标红报告 + 论文文件，说"帮我改写标红段落"

## 支持语言

- 中文论文（完整支持）
- 英文论文（禁用短语表已包含英文对照）
